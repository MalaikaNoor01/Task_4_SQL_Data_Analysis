# Task_4_SQL_Data_Analysis# Task 4: SQL for Data Analysis

## Objective
To extract, manipulate, and analyze eCommerce database records using advanced SQL queries, aggregations, joins, and performance optimization techniques.

## Tools Used
* SQLite / MySQL / PostgreSQL

## Files Included
* `queries.sql`: Contains all SQL scripts written for data extraction, joins, subqueries, and views.
* `screenshots/`: Folder containing execution output screenshots.

## Interview Questions & Answers
1. **WHERE vs HAVING:** WHERE filters rows before aggregation, while HAVING filters groups after aggregation.
2. **Types of Joins:** INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN.
3. **ARPU Calculation:** SUM(revenue) / COUNT(DISTINCT user_id).
4. **Subqueries:** A query nested inside another query.
